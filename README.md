# DigitalWork · Freelance Escrow

[เปิดเดโมสำหรับการศึกษาบน GitHub Pages](https://relaxtimee.github.io/csi301-freelance-escrow/) เพื่อดูรายการงานและประวัติบน Sepolia แบบอ่านอย่างเดียว การสาธิตที่ต้องลงนามผ่าน MetaMask ใช้ฉบับรันบนเครื่องตามขั้นตอนด้านล่าง

เว็บภาษาไทยสำหรับ Assignment 8 ใช้ React, Vite, TypeScript strict และ viem เชื่อมกับ [FreelanceEscrow บน Sepolia](https://sepolia.etherscan.io/address/0x73Af871f0F57cA2EC4Ad8D4A7E075b2CFf037CeC#code) โดยตรง

## เปิดเว็บบนเครื่อง

ใช้ Node.js 22.12 ขึ้นไปและ npm เปิด terminal ในโฟลเดอร์ที่มี `package.json` แล้วรัน

```sh
npm ci
npm run dev
```

เปิด URL ที่ Vite แสดง ปกติคือ `http://localhost:5173` หน้าแรกอ่านข้อมูลจากอินเทอร์เน็ตได้ทันที การส่งธุรกรรมใช้ MetaMask บน Ethereum Sepolia (chain ID `11155111`) ค่าจ้างและค่า gas ใช้ Sepolia ETH

```sh
npm test
npm run build
npm run preview
```

คำสั่งทดสอบเปิด Anvil เฉพาะบน loopback และปิดเมื่อจบชุดทดสอบ บน Windows ใช้ x64 ส่วน macOS และ Linux ใช้ x64 หรือ arm64 ติดตั้ง optional dependencies ของ npm ตามค่าเริ่มต้น คำสั่ง build ตรวจ TypeScript และสร้างเว็บใน `dist/`

## สาธิตการจ้างงานด้วยสองบัญชี

1. เตรียมบัญชี A สำหรับผู้ว่าจ้างและบัญชี B สำหรับฟรีแลนซ์ ทั้งสองบัญชีต้องมี Sepolia ETH สำหรับ gas และ A ต้องมียอดสำหรับค่าจ้างด้วย เปิดเครือข่ายทดสอบ Sepolia ใน MetaMask หากซ่อนไว้
2. เชื่อมกระเป๋า A กด **สร้างข้อตกลง** กรอกชื่อ รายละเอียด ที่อยู่ B และค่าจ้าง เช่น `0.001` ETH ระบุจำนวนวันเต็ม เช่น `7` ยืนยันในกระเป๋า หลังบันทึกลงบล็อก เว็บเปิดเลขงานใหม่พร้อมกำหนดส่งจริง
3. จากหน้ารายละเอียด ใช้ A กด **ฝากค่าจ้าง** ตรวจยอดและยืนยัน เป็นธุรกรรมที่สอง ระยะเวลาส่งงานเริ่มตั้งแต่ธุรกรรมสร้างงาน
4. เปลี่ยนเป็นบัญชี B ใน MetaMask อนุญาตให้เว็บไซต์เห็นบัญชีนี้ เปิด **งานของฉัน** เลือกงานแล้วกรอก URL หรือแฮชผลงาน กด **ส่งมอบงาน** และยืนยันภายในกำหนด ข้อมูลหลักฐานในสัญญาเป็นสาธารณะ
5. เปลี่ยนกลับเป็น A เปิดหลักฐาน ตรวจยอดและที่อยู่ปลายทาง กด **อนุมัติและจ่ายเงิน** เมื่อสำเร็จ สถานะเป็น **จ่ายเงินแล้ว** และ ETH เข้าบัญชี B เปิด Transaction Hash ในประวัติเพื่อดูรายละเอียดบน Etherscan
6. สาธิตข้อพิพาทด้วยงานใหม่ที่ฝากเงินแล้ว A หรือ B เปิดข้อพิพาทได้ทั้งก่อนและหลังส่งผลงาน ผู้ดูแลเชื่อมบัญชีที่ตรงกับ `owner()` เพื่อเลือกจ่ายให้ B หรือคืน A การทดสอบด้วย Anvil มีบัญชีผู้ดูแลแยกและตรวจผลได้ทั้งสองทาง

## การเชื่อมต่อสัญญา

| หน้าที่ | ฟังก์ชัน |
|---|---|
| รายการและรายละเอียด | `getJobCount`, `getJob`, `getContractBalance`, `owner` |
| สร้างและฝากเงิน | `createJob`, `depositPayment` พร้อม value ตรงกับค่าจ้างในหน่วย wei |
| ส่งมอบและตรวจรับ | `submitWork`, `approveAndRelease` |
| เปิดและตัดสินข้อพิพาท | `raiseDispute`, `resolveDispute` |

ABI อยู่ใน `src/abi.ts` ที่อยู่สัญญาและการเรียกเครือข่ายอยู่ใน `src/chain.ts` ประวัติกรองตามที่อยู่สัญญาและเลขงานตั้งแต่บล็อก 12075114 ใช้ Blockscout สำหรับเหตุการณ์เก่า และอ่านช่วงบล็อกล่าสุดผ่าน RPC หากดัชนีไม่พร้อมใช้งาน เว็บลองอ่านประวัติผ่าน RPC ทั้งหมด บริการที่ตัดข้อมูลย้อนหลังอาจต้องใช้ archive RPC

เว็บอ่านข้อมูลผ่าน Sepolia RPC สาธารณะที่ใช้งานได้โดยไม่ต้องมี API key เปิดโปรเจกต์ได้ทันทีโดยไม่ต้องสร้างไฟล์ `.env` เมื่อต้องส่งธุรกรรม ผู้ใช้ยืนยันใน MetaMask ซึ่งเป็นผู้เก็บกุญแจของบัญชี

## การตรวจสอบ

- Unit tests ตรวจสิทธิ์ทุกสถานะ ขอบเขตเวลาส่งงาน การแปลง ETH เป็น wei และข้อมูลสร้างงานที่ไม่ถูกต้อง
- Integration tests คอมไพล์ซอร์สที่ Etherscan ยืนยันจาก `tests/fixtures/FreelanceEscrow.sol` แล้ว deploy บน Anvil ทดสอบผ่านฟังก์ชันส่งธุรกรรมตัวเดียวกับหน้าเว็บ ตรวจทั้งยอดเงินจริงบน EVM จำลองและการปฏิเสธการจ่ายซ้ำ
- หากกระเป๋าปฏิเสธลายเซ็น สามารถแก้ข้อมูลแล้วส่งใหม่ได้ หากเว็บแสดง hash แล้วแต่ RPC ยังตรวจผลไม่ได้ ให้กด **ตรวจสถานะ** หรือเปิด hash บน Etherscan
